# BAITTERS - CZ/SK ESPORT ORGANIZACE

Oficiální webová stránka týmu BAITTERS - Cesko-slovenské esportové organizace se zaměřením na Counter-Strike 2.

## 🎮 O nás

BAITTERS je začínající český esport tým s ambicí vyhrávat turnaje a reprezentovat Česko a Slovensko na mezinárodní scéně. Náš tým se skládá z talentovaných hráčů zaměřených na profesionální hraní Counter-Strike 2.

## 🌐 Webové stránky

Web je hostován na GitHub Pages a je dostupný na: [https://wraxczsk1.github.io/BAITTERS/](https://wraxczsk1.github.io/BAITTERS/)

## 📋 Struktura stránek

- **Home** - Hlavní stránka s posledními zápasy a novinkami
- **O nás** - Informace o organizaci a naší vizi
- **Náš tým** - Profily jednotlivých hráčů
- **Zápasy** - historie a předstojící zápasy
- **Partneři** - Informace o partnerství
- **Galerie** - Fotografie z akcí
- **Kontakt** - Kontaktní formulář a informace

## 🎨 Design a barvy

Web je navržen s moderním dark designem:
- **Primární barva**: #0a0a0d (velmi tmavá šedá)
- **Sekundární barva**: #b30000 (tmavě červená)
- **Akcentní barva**: #ff3b3b (jasně červená)

Design je plně responzivní a funguje na všech zařízeních (mobil, tablet, desktop).

## 🚀 Jak spustit lokálně

1. Naklonuj repozitář:
```bash
git clone https://github.com/wraxczsk1/BAITTERS.git
```

2. Jdi do složky:
```bash
cd BAITTERS
```

3. Otevři `index.html` v prohlížeči

## 📝 Jak upravit web

1. Edituj HTML soubory v textovém editoru (VS Code, Sublime Text, apod.)
2. Upravuj styly v `style.css`
3. Přidej nové obrázky do repozitáře
4. Commituj změny do Gitu
5. GitHub Pages se automaticky aktualizují
