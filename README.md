# BAITTERS – Oficiální Web

Tento projekt je jednoduchý statický web vytvořený pro esport organizaci **BAITTERS**, zaměřenou na hru **Counter‑Strike 2**.

Web obsahuje základní informace o organizaci, týmové sestavě a kontaktech.

---

## Obsah webu

- **Home** – úvodní stránka s novinkami
- **O nás** – informace o organizaci BAITTERS
- **Náš tým** – CS2 MAIN sestava + hráčské profily
- **Kontakt** – kontaktní údaje a odkazy
